# Katkı rehberi

Teşekkürler! Bu model tartışmaya açık olarak yayımlandı.

**Veri düzeltmesi veya yeni veri:** "Veri düzeltmesi" şablonuyla bir Issue açın. Kaynağı (KAP bildirim linki, TEFAS tarihi, rapor sayfası) mutlaka ekleyin. Kaynaksız veri önerileri modele alınamaz.

**Yöntem önerisi:** Discussions bölümünde bir başlık açın. Önerinizin hangi parametreyi veya denklemi değiştirdiğini ve sonuca etkisini belirtin.

**Kod değişikliği:** Fork edip pull request gönderin. `index.html` tek dosyadır; değişiklikten sonra dosyayı tarayıcıda açıp tüm sekmelerin çalıştığını kontrol edin.

**Üslup:** Kişi ve kurumlar hakkında yalnızca kaynağa dayalı, doğrulanabilir ifadeler kullanın. Suç isnadı içeren yorumlar kaldırılır.
